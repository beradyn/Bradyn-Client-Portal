name: Bradyn demo scope
description: Product boundary for the Bradyn Expo portal before real backend integration.
---

Bradyn is currently a design/demo app: use fictional information and temporary client/admin logins, and do not connect a real database.

**Why:** the user explicitly deferred real database integration while shaping the app design.

**How to apply:** keep new portal features functional against local demo state; do not request database credentials or add a live backend unless the user changes this scope.
